Quick Reference

Seven Key Concepts

These terms are useful for understanding how web addresses identify resources and help browsers access them.

01

URL

Uniform Resource Locator. A type of address that identifies a resource and provides a way to locate or access it.

02

URI

Uniform Resource Identifier. A general term for a string that identifies a resource. URLs are commonly described as a type of URI.

03

URN

Uniform Resource Name. A type of URI intended to identify a resource by a persistent name rather than by its current network location.

04

Scheme

The opening part of a URL that indicates the access method, such as https or http.

05

Domain Name

A readable name, such as example.com, used to identify a host on a network.

06

Path

The part after the host that helps identify a resource or route, such as /help/contact.

07

Query Parameter

Additional information included after a question mark, often as name-value pairs such as ?page=2.
