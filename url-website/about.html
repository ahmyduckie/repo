I am a cybersecurity major interested in information technology and cybersecurity. This website was created as a web development project to present research about URLs and explain how web addresses work.

The project builds on my first assignment, which covered the structure, purpose, history, and security of URLs. The goal is to make the topic easier to understand through short explanations, examples, and links to further reading.

Project Goals

  • Explain the main parts of a URL.
  • Describe how browsers use URLs to access resources.
  • Introduce URL-related security concerns.
  • Practice organizing information using HTML and styling it with CSS.
