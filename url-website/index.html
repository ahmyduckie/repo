Introduction

A URL stands for Uniform Resource Locator. It is a web address that tells a browser where a resource can be found and how it should be accessed. URLs may look like simple lines of text, but they contain different parts that each have a purpose.

This website introduces URL structure, explains how browsers use URLs, and discusses security concerns that can come from misleading or unfamiliar web addresses. It builds on the research topic from Assignment 1 and will be expanded in later project milestones.

Key Terms

  • URL: An address used to locate a resource.
  • URI: A general identifier for a resource.
  • Domain name: A readable name used to identify a host.
  • Scheme: The part that indicates how a resource is accessed, such as HTTPS.
  • Path: The part that identifies a location or resource on a host.
